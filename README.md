# PRO-TCHAD-STUD

<img width="739" height="415" alt="images (1)" src="https://github.com/user-attachments/assets/01ca3526-aa50-40c5-ba9e-62ed29258d68" />


Plateforme éducative avancée créée par la **Communauté Tchadienne** pour comprendre tous les protocoles réseau en pratique.

## Objectif

Apprendre et expérimenter les protocoles réseau à travers des commandes prêtes à lancer, des explications claires et des démonstrations Python.

## Catégories couvertes

### Couche Réseau
- IP (IPv4, IPv6), ICMP, IGMP, ARP, RARP, NDP, MPLS

### Couche Transport
- TCP, UDP, SCTP, DCCP, QUIC

### Routage
- BGP, OSPF, RIP, IS-IS, EIGRP

### Attribution d'adresses
- DHCP, BOOTP

### Résolution de noms
- DNS, mDNS, LLMNR

### Web
- HTTP, HTTPS, HTTP/2, HTTP/3, WebSocket

### Transfert de fichiers
- FTP, FTPS, SFTP, TFTP, SCP, Rsync

### Courrier électronique
- SMTP, POP3, IMAP

### Accès distant
- SSH, Telnet, RDP, VNC

### Sécurité
- TLS, SSL (obsolète), IPsec, Kerberos, OAuth 2.0, OpenID Connect

### Synchronisation
- NTP, PTP

### Voix et vidéo
- SIP, RTP, RTCP, RTSP, WebRTC

### Réseaux sans fil
- Wi-Fi (IEEE 802.11), Bluetooth, Zigbee, Z-Wave, LoRaWAN, NFC

### Internet des objets (IoT)
- MQTT, CoAP, AMQP, DDS, XMPP

### Annuaire
- LDAP, LDAPS

### Virtualisation et VPN
- OpenVPN, WireGuard, L2TP, PPTP, GRE

### Gestion réseau
- SNMP, NetFlow, Syslog

### Industriel
- Modbus, OPC UA, CAN Bus, DNP3, BACnet, PROFIBUS, EtherCAT

## Installation

```bash
pip install -r requirements.txt
```

## Utilisation

```bash
sudo python pro_tchad_stud.py
```

> Certaines fonctionnalités nécessitent les droits root (scapy, ICMP, sniffing).

## Avertissement

Ce script est **strictement éducatif**. Utilisez-le uniquement sur vos propres réseaux et appareils. Toute utilisation malveillante est interdite et de votre seule responsabilité.
